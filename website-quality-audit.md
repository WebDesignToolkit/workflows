# Website quality audit

1. Get explicit permission, target pages, audience and baseline requirements.
2. Run accessibility-review, design-system-review and performance-triage skills.
3. Capture issues with severity, concrete reproduction and screenshots/measurements.
4. Prioritize fixes; do not modify production automatically.
5. Verify in a staging environment; report before and after with matching methodology.
6. Produce a handoff checklist for the project owner.
