# Brief to launch

1. Write a goal statement, page inventory, audience, constraints and success metrics.
2. Select a stack based on requirements, licensing and technical skills; consult canonical catalog.
3. Establish content hierarchy, UX wireframes and accessibility acceptance criteria.
4. Create typography, colors, spacing and interaction tokens; use design-system as a reference.
5. Build locally with framework-appropriate tools; use tested open-source assets only.
6. Run keyboard, responsive, visual, functional and performance checks.
7. Seek approval for launch and any account or DNS changes.
8. Publish from user-controlled environments and record deployment provenance.
