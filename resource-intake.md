# Resource intake

Trigger: a contributor proposes a free/open-source project.

1. Search catalog for duplicate upstream IDs.
2. Capture owner/repository, category, upstream metadata and last-checked date.
3. Review license status; do not assume that an API SPDX value is legal verification.
4. Review security posture and maintenance signals.
5. Add it as candidate and run catalog validation.
6. Open a review issue with evidence and an assigned maintainer.
7. Only promote to reviewed with actual hands-on evidence documented in knowledgebase.

Output: one canonical resource record, review evidence and an audit trail.
